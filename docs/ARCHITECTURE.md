# Бункер: Протокол — план продукту

## Мета

Сервер-авторитетна онлайн-гра для 4–12 людей без ведучого. Клієнт лише показує стан і надсилає рішення; роздача, таймери, черга, голосування, нічиї, випадкові події та фінальний результат визначаються сервером.

## Ігровий цикл

1. Гравець створює кімнату, налаштовує темп і правила та ділиться шестисимвольним кодом.
2. Усі учасники підтверджують готовність. Коли досягнуто мінімум і всі готові, гра запускається автоматично.
3. Сервер генерує катастрофу, бункер, стан поверхні й приватне досьє для кожного.
4. У кожному раунді активні гравці по черзі відкривають характеристику. Першою обов’язково відкривається професія; прострочений хід відкривається автоматично.
5. Після загальної дискусії система відкриває голосування. Якщо є нічия, запускається коротке переголосування; повторну нічию вирішує серверний жереб.
6. Після виключення система показує випадкову обставину всередині бункера або на поверхні.
7. Коли активних людей залишається стільки, скільки місць, сервер відкриває фінальні досьє та формує підсумок шансів групи.

## Сервер і дані

- Cloudflare Worker приймає всі ігрові дії.
- D1 зберігає кімнати, гравців і журнал подій.
- Кожен гравець отримує приватний локальний токен; чужі приховані картки сервер не повертає.
- Кожне опитування стану також просуває прострочені фази за серверним часом. Після паузи гра коректно наздоганяє стан при наступному підключенні.
- Дії ідемпотентні: повторне натискання не створює подвійного голосу чи відкриття.

## Інтерфейс

- Старт: створити кімнату або приєднатися за кодом.
- Лобі: код-запрошення, список присутніх, правила й готовність.
- Гра: спільний сценарій, картки учасників, фазовий таймер, журнал подій та приватне досьє.
- На мобільному: пріоритет поточного ходу, компактні картки та нижня панель дій.

## Межі першої версії

- Текстове спілкування не замінює голосовий зв’язок; гравці можуть користуватися будь-яким звичним дзвінком.
- Реєстрація не потрібна. Повернення у кімнату працює на тому самому пристрої через локальний приватний токен.
- Гра є авторською реалізацією жанру й не копіює картки або графіку конкретного видання.
