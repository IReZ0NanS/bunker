# Бункер: Протокол

Автономна багатокористувацька вебгра для 4–12 гравців. Реєстрація не потрібна: можна одразу ввійти гостем, створити кімнату й додати ботів. Боти автоматично відкривають характеристики та голосують.

У лобі творець кімнати налаштовує правила, кількість місць і час кожної фази. Для неквапливої живої гри можна вимкнути всі таймери: після відкриття картки гравець говорить скільки потрібно й передає хід кнопкою, а творець вручну запускає дискусію та голосування.

Випадкові події між раундами вимкнено. Натомість кожен гравець отримує одноразову активну картку: заміну власної характеристики, обмін, розкриття або зміну чужої картки, імунітет чи подвійний голос. Характеристики роздаються без повторів у межах кімнати; набори професій, станів здоров’я, фобій, фактів, хобі та багажу суттєво розширені.

## Простий локальний запуск

Потрібен Node.js 22.13 або новіший.

На macOS двічі натисніть `Запустити Бункер.command` — сайт і сервер запустяться разом, а сторінка відкриється у браузері. Щоб завершити роботу, двічі натисніть `Зупинити Бункер.command`.

Під час першого запуску файл сам підготує необхідні компоненти. Наступні запуски будуть швидшими.

Ручний спосіб:

```bash
npm install
npm run dev
```

Після запуску відкрийте адресу, яку покаже сервер. Для перевірки кількох гравців використовуйте різні браузери або приватні вікна.

## Перевірка збірки

```bash
npm run build
npm run lint
```

## Як влаштована гра

- `worker/game-api.ts` — серверні кімнати, авторизація сесій, фазовий автомат і голосування.
- `worker/game-data.ts` — авторські набори характеристик, катастроф, бункерів та подій.
- `app/game-client.tsx` — усі екрани й взаємодії гравця.
- `db/schema.ts` — довговічні дані кімнат і гравців у D1.
- `docs/ARCHITECTURE.md` — повний продуктовий та технічний план.

Гра не потребує адміністратора або окремого ведучого. Кожен запит синхронізації перевіряє серверний час і безпечно просуває прострочені фази.
